# Contribuir

Describe el problema, el cálculo esperado, las fuentes y un ejemplo sintético mínimo. Los cambios deben mantener definiciones, unidades y pruebas reproducibles. No aportar informes reales en issues, pull requests o pruebas.

Las propuestas de contenido distinguirán fuente, observación, interpretación y resultado esperado. No añadir promesas de posicionamiento, afiliaciones, clientes o resultados sin soporte.

Ejecuta `npm test` y `npm run check`. La aprobación de una corrección de código no autoriza publicar nuevos materiales de clientes ni modificar la web de la agencia.
