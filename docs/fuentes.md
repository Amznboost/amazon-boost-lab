## Jerarquía de evidencia

1. Informe original autorizado con definiciones y periodo, conservado en privado.
2. Tabla derivada revisada y reproducible, con permiso para compartirla.
3. Publicación documental existente, citada con su alcance.
4. Hipótesis de trabajo o ejemplo sintético, identificado expresamente.

Una fuente de Amazon sobre una métrica no certifica los cálculos particulares de Amazon Boost. Una publicación de Amazon Boost no es verificación externa de su propio caso.

Para cada cifra nueva se utilizará el [registro de fuentes](../templates/registro-fuentes.csv). Los enlaces ayudan a comprobar el origen; no se utilizarán citas de autoridad para sostener una afirmación distinta.
